PROJET : CRÉEZ 
VOTRE PROPRE JEU 
TOP TRUMP 
 
 
 
 1. Objectif du projet 
Votre mission est de concevoir et développer une application web permettant de jouer à votre propre version 
d'un jeu de type Top Trump. 
Le principe général est simple : les joueurs possèdent des cartes contenant différents attributs chiffrés et 
doivent comparer ces attributs afin de remporter les cartes de leurs adversaires. 
Vous n'avez pas à reproduire exactement les règles classiques. Vous êtes libres d'inventer votre propre 
univers, vos propres cartes et vos propres règles. L'objectif est de créer un jeu cohérent, fonctionnel et 
amusant à jouer. 
 
 2. Les cartes 
Votre jeu devra contenir au minimum 20 cartes différentes. 
Vous êtes totalement libres concernant le thème : dinosaures, voitures, super-héros, pays, planètes, 
créatures fantastiques, personnages de jeux vidéo, animaux, robots ou un univers totalement original. 
Chaque carte devra posséder au minimum : 
 Un nom 
 Une image ou une illustration 
 Au moins 4 attributs chiffrés 
 Toute autre information que vous jugerez utile 
Exemple : Tyrannosaurus Rex 
Attribut Valeur 
Force 95 
Vitesse 45 
Intelligence 60 
Dangerosité 100

 3. Les règles du jeu 
Vous devez créer un système de jeu inspiré du principe de comparaison des cartes. Les règles exactes sont 
à votre choix. 
 
Vous devrez définir clairement : 
 Combien de cartes possède chaque joueur au départ ? 
 Combien de cartes un joueur peut-il avoir en main ? 
 Comment un tour se déroule-t-il ? 
 Comment choisit-on l'attribut à comparer ? 
 La valeur la plus haute gagne-t-elle toujours ? 
 Que se passe-t-il en cas d'égalité ? 
 Que devient une carte perdue ? 
 Les cartes sont-elles remises en jeu ? 
 Existe-t-il une pioche ? 
 Comment gagne-t-on la partie ? 
Vous pouvez inventer vos propres mécanismes. Le plus important est que les règles soient compréhensibles, 
cohérentes et jouables. 
 
 4. Technologies obligatoires 
Votre application devra être développée avec les technologies suivantes : 
 HTML 
 CSS 
 JavaScript 
 PHP 
Vous devrez utiliser ces technologies pour créer une véritable application web fonctionnelle. 
 
 5. Stockage des cartes 
Les données de vos cartes ne doivent pas uniquement être écrites directement dans votre code JavaScript. 
Les cartes devront être stockées dans une source de données externe : 
 Option A : un fichier JSON 
 Option B : une base de données 
Vous pouvez également stocker d'autres informations utiles : joueurs, scores, parties, historique, etc.

 6. Modes de jeu 
Votre jeu devra être réellement jouable. Vous devrez implémenter au moins un des modes suivants : 
 Joueur contre ordinateur : l'ordinateur doit pouvoir jouer en respectant les règles. 
 Deux joueurs sur la même machine : vous devrez gérer les tours et les informations visibles ou cachées. 
 Deux joueurs sur des machines différentes : vous pouvez utiliser une API, PHP côté serveur, une base de 
données partagée ou des requêtes AJAX / Fetch. 
 
 7. Interface et design 
Votre application devra posséder une interface claire et agréable à utiliser. 
 L'affichage des cartes 
 La lisibilité des attributs 
 Les actions possibles pour le joueur 
 L'affichage du score 
 Les messages indiquant ce qui se passe pendant la partie 
 L'affichage du gagnant 
Le design graphique est libre. Vous êtes encouragés à créer un véritable univers visuel autour de votre 
thème. 
 
 8. Minimum obligatoire 
 Au moins 20 cartes différentes 
 Au moins 4 attributs chiffrés par carte 
 Une application utilisant HTML, CSS, JavaScript et PHP 
 Les cartes stockées dans un fichier JSON ou une base de données 
 Un système de jeu fonctionnel permettant de comparer les cartes 
 Des règles clairement définies 
 Un système permettant de déterminer le gagnant d'une partie 
 Au moins un mode de jeu fonctionnel 
 
 
9. Améliorations possibles 
facultatives 
Une fois le minimum obligatoire réalisé, vous êtes libres d'améliorer votre jeu, par exemple avec : 
 Une IA difficile à battre 
 Des sons et de la musique 
 Des animations 
 Un système de classement 
 La sauvegarde / restauration d'une partie en cours
